# nervd 设计图 sample

这是一个与真实云效、Codeup、Flow、Jenkins 隔离的整体 UI 展示层，用于评估信息架构、交互路径和交付效果。

## 启动

在仓库根目录执行：

```bash
pnpm sample:dev
```

然后访问 <http://localhost:1422/>。

构建展示版：

```bash
pnpm sample:build
```

## 展示范围

- 总览：系统状态、工作项统计、流水线健康度、动态流
- 工作台：需求 / 缺陷 / 任务列表、搜索、关联筛选、父子任务、迭代上下文、关联仓库、代码操作、评论
- 追溯：工作项 → 多个关联仓库 → 分支 / 提交 / MR / 多环境 CI，并可按 CI 环境单独触发或打开 mock 日志抽屉
- 迭代：迭代基础分支、默认 `dev` 开发分支、需求来源和手动创建 / 管理分支入口
- 流水线：运行历史、通过率、触发入口、仓库 CI 绑定
- 仓库 CI：供应商、默认分支、最近构建、健康度和追溯规则
- 设置：云效连接、追溯规则、Flow / Jenkins、安全策略

需求与仓库按 1:N 展示：需求详情会列出多个仓库，每个仓库独立呈现分支、提交、MR 和多个环境 CI；CI 状态明确表示该环境最近一次运行结果，触发入口位于对应仓库 / 环境下。设置页也使用多选仓库 mock。按钮和表单只改变本地 mock 状态或显示提示，不会调用真实接口。默认使用只读策略，符合当前工程的 `allowWriteOps` 设计。
