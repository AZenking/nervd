## 3. 核心旅程走查

### J1 首次配置（PAT → 组织 → 项目空间 → 仓库）
`needSetup` 直接全屏设置页，起点正确。但流程为"填令牌+组织 → 保存 → 自动拉项目/仓库 → 再进设置选项目空间 → 再保存"，**两轮保存来回**；项目空间下拉初始文案"项目加载中…/点击刷新"是混排态；校验报错文案偏开发者口吻（`当前 "xx" 像是名字`）。

### J2 日常巡逻（总览 → 迭代）
总览统计带 + 流水线墙 + 仓库 CI + 状态分布的层级合理，点速览进详情动线通。**但去了回不来**（无返回，P0-2）。

### J3 需求详情 → 追溯 → CI → 日志（核心旅程）
详情一长页：hero → 8 格基本信息 → 描述 → 子任务/缺陷 → 仓库表 → 评论。两个问题：
- **首屏优先级倒挂**：高频问的"走到哪了"（分支/CI/MR 状态）在仓库表，被 8 格静态信息挤到折叠线下；
- **核心卖点降级为弹窗**：完整追溯链路是 560px `TraceDialog`，入口仅详情视图右上角。"一屏看全"只在 Req 类别仓库表部分兑现。

### J4 写操作（建分支 / MR / 触发构建 / 改子任务）
全 app 设计最用心的部分（亮点 1、2）。毛刺：对话框内再弹 AlertDialog（dialog-in-dialog）；Jenkins 向导强制"至少两个参数分别映射环境和分支"，单参数 Job 直接不可用。

### J5 环境与策略 / 工作区设置
两页各持 settings 表单快照，保存全量 `saveAll`（P0-1）；"环境与策略"保存按钮在页首 hero，滚到底后**保存入口不可见**，与"工作区设置"的 sticky 底栏不一致。

## 4. 值得保持的亮点

1. **可解释的禁用**：建分支/MR 的 `disabledReason` 链逐态说清（占位迭代 / 编号不可用 / 未选模板 / 正在查询 / 已存在…）+ Tooltip。
2. **写操作安全模式**：`allowWriteOps` 门控（禁用 + 原因）→ AlertDialog 确认 → busy 态，API 侧再拒绝（双重门控）；只读/可写徽章常驻。
3. **空态分级**：迭代工作项空态按 `loadingList / 筛选中 / nextToken / usingFallback` 四种组合给不同文案与行动指引。
4. **长列表体验**：240px 预取哨兵自动翻页、"已加载全部 · 共 N 项"收尾、计数口径诚实。
5. **状态语义统一**：`--sig-*` + `StatusDot` 与 `runGroup` 同一套分组规则，RUNNING 呼吸脉冲。
6. **诚实的占位标注**：占位迭代明示"占位数据"，子任务注明"新增请在云效网页端操作"。
7. **通知到行动闭环**：构建完成 toast 带"查看"直达 Jenkins/Flow。

## 5. 问题清单

### P0 —— 数据丢失或用户迷失

**P0-1 双设置页并发编辑冲突**
「环境与策略」与「工作区设置 → CI 集成」维护几乎相同的表单（Jenkins 实例 + 仓库 CI 绑定，代码近乎复制），各持独立 form 副本互不感知，保存全量覆盖 `saveAll`。A 页改未保存 → 切 B 页（从 store 重新初始化旧值）→ B 保存 → **A 的修改静默丢失**。无 dirty 提示、无离开确认。
证据：`EnvironmentPolicySettings.tsx:26`、`SettingsView.tsx:55`、`store/app.ts:522`。

**P0-2 无导航历史，多条断链**
面包屑纯展示不可点（`Shell.tsx:64-68`）；子任务/缺陷点击后 `select()` 覆盖选中项（`RequirementDetails.tsx:846/855`），**子任务详情回不到父需求**，面包屑也无父子链；总览跳详情后回不到总览。桌面用户对"⌘← / 面包屑回上级"有强预期。

## 6. 改造清单（带验收标准，按优先级）

> 每项给出改造方向 + 可勾选的验收标准。A 系列对应上述问题编号。

### A1（P0-1）设置编辑单会话
**方向**：一个设置模型 + 一个共享 draft store + dirty 守卫；「环境与策略」成为「工作区设置」的快捷分区而非独立副本。
- [ ] 全应用只存在一份可编辑 settings 草稿；两入口读写同一草稿
- [ ] 任一入口有未保存修改时，切走再切回，修改保留
- [ ] dirty 时切换视图出现"保存 / 放弃"确认
- [ ] 两处 Jenkins 实例 + 仓库 CI 绑定 UI 收敛为同一组件（消除复制粘贴双实现）
- [ ] 场景回归：A 页改 Token 不保存 → B 页保存其他项 → A 页刷新后 Token 修改仍在（或被明确确认丢弃）

### A2（P0-2）导航栈与面包屑
**方向**：selection history + 可点面包屑 + 父子层级链。
- [ ] 面包屑可点击：根节点回到对应视图
- [ ] 需求详情面包屑显示层级链：`迭代 › 父工作项 › 当前子项`
- [ ] 子任务详情一步回到父需求（面包屑或"返回父需求"）
- [ ] ⌘← / Ctrl+← 后退，至少覆盖视图切换与工作项选择两类历史
- [ ] 后退后滚动位置不重置（列表场景）

### A3（P1-3）主导航修正
- [ ] 「工作区」点击即切 iteration 视图
- [ ] iteration / requirement 视图时「工作区」高亮
- [ ] 无点击无响应的导航项（grep 复查）

### A4（P1-4）反馈渠道归一
- [ ] 全应用 `window.confirm` 出现为零（grep 验证）
- [ ] 确认类 → AlertDialog；校验错误 → 字段内联；操作结果 → toast，三类不混用
- [ ] 文案口吻统一（无 `✗` 等符号、非命令式）

### A5（P1-5）向导内写操作确认改两段式
- [ ] SubtaskEditDialog / JenkinsBuildDialog 内不再出现第二层模态
- [ ] 触发按钮一次点击进入"确认触发"态（3–5s 超时回退），二次点击执行
- [ ] Esc / 取消路径可用；busy 态可见

### A6（P1-6）迭代分组展开模型
- [ ] 每个迭代独立展开状态（Map 而非单布尔）
- [ ] chevron 在所有迭代行渲染；点 chevron 仅展开/收起，不切视图
- [ ] 点行主体才切换迭代

### A7（P1-7）侧栏列表截断提示
- [ ] 超过 12 条时显示"还有 N 条"，点击跳迭代视图完整列表

### A8（P1-8）保存入口
- [ ] 「环境与策略」保存按钮 sticky（或页首+页尾双入口）
- [ ] dirty 时保存按钮有明显视觉提示（与 A1 联动）

### A9（P1-9）占位元素统一策略
- [ ] 所有占位入口 disabled + tooltip"暂未接入，去云效网页端"
- [ ] 无"可点击但零反馈"元素（走查复查）

### A10（P1-10）详情页信息优先级
- [ ] 首屏可见各仓库 CI / MR 状态摘要（仓库表上移或加状态摘要条）
- [ ] 基本信息 8 格压缩为一行元信息或可折叠
- [ ] 常用操作（打开追溯、触发 CI）在首屏可达

### A11（P1-11）Jenkins 向导放宽约束
- [ ] 单参数 Job 可触发（仅映射分支或环境其一即可）
- [ ] "环境/分支参数映射"首用时有一句解释或示例
- [ ] 无法映射时给出可行动的报错（而非笼统"至少需要两个参数"）

### A12（P2 打包）
- [ ] 占位列 `—` 附原因说明或收敛空列
- [ ] `title` 全部替换为 Tooltip 组件
- [ ] 偏差徽章色接入 `--sig-*` token
- [ ] 建立术语表并全量统一（仓库指称、设置入口名称、写操作开关路径）
- [ ] 迭代页与详情页加"上次刷新 hh:mm:ss"
- [ ] `InfoItem` 移除 hover 或赋予点击行为
- [ ] 删除 `store/layout.ts` 死代码（若按第 7 节复活分栏则改造后再删）
