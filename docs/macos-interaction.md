# macOS 操作对齐

本轮在保留上一轮操作改动的基础上调整布局（统一页头、可拖动分栏、窄窗口适配），不改变既有配色、字体、字号、图标与业务 IPC。Apple HIG 作为平台布局与操作依据；具体尺寸与阈值采用下列产品约定。

参考：[macOS](https://developer.apple.com/design/human-interface-guidelines/designing-for-macos/)、[菜单](https://developer.apple.com/design/human-interface-guidelines/menus)、[上下文菜单](https://developer.apple.com/design/human-interface-guidelines/context-menus)。

## 布局与窗口

| 项 | 行为 |
| --- | --- |
| 窗口尺寸 | 默认 1360×860；最小 800×640（tauri.conf.json） |
| 页头拖拽 | 页头空白区按住拖动即可移动窗口；按钮、输入框、菜单等交互控件不触发拖拽 |
| 侧栏宽度 | 右缘 1px 分隔线可拖动（200–300px）；方向键 ±8px（Shift ×4）、Home/End 到上下限；双击恢复 256px |
| 列表宽度 | 迭代列表与详情间分隔线可拖动（280–480px）；键盘与双击恢复 360px 同上 |
| 宽度记忆 | 拖动结束 150ms 内合并写入本地 `nervd-layout`，重启后恢复；窗口收窄只限制展示尺寸，不覆盖已保存偏好 |
| 侧栏自动收放 | 容器 <1180px 自动收为图标栏；页头 / 侧栏入口点击可临时展开（会话态，不写偏好）；放大窗口恢复原偏好 |
| 单栏模式 | 工作区 <760px 时选工作项进入全宽详情，「返回列表」（或 Esc）恢复筛选、分页、多选、光标与滚动位置 |
| 移动抽屉 | 浏览器 <768px 沿用侧栏抽屉；桌面窗口最小宽度 800px |

页头排列统一为「导航与标题 → 当前范围 → 页面操作」：空间不足先截断标题与范围名称，再把次要操作收入「更多」菜单，主要操作保持可达；筛选与分类位于页头下方随页头固定，正文独立滚动。分支名、代码与日志仅在自身区域横向滚动。

## 操作约定

| 操作 | 行为 |
| --- | --- |
| 普通单击 | 选中并预览当前项，保留列表现场 |
| 双击 | 打开独立详情工作台 |
| Enter | 打开当前项预览；原生按钮与编辑器保留自身操作 |
| Command 单击 | 切换批量选择；Control 在跨平台键盘下作为补充 |
| Shift 单击 | 按当前可见行顺序选择锚点到目标的区间 |
| Command A | 选择当前页可见工作项；输入框中保留全选文字 |
| Esc | 关闭浮层、清除多选或关闭分栏，不离开完整页面 |
| Command [ / ] | 后退 / 前进，恢复列表上下文 |
| Command , | 打开设置 |
| Command F | 聚焦当前搜索；页面无搜索框时打开已有命令面板 |
| Command R | 调用当前页已有刷新入口；编辑中不重载页面 |

保留 j/k、x、g 系列快捷操作。中文输入法组合期间不响应全局快捷键。菜单、键盘及按钮共用现有命令执行路径；只读模式不能通过批量操作绕过门控。

## 恢复与失败处理

- 导航记录仅存本地界面状态，不包含凭据；无效记录回总览。
- 后退与前进恢复迭代、类别、筛选、页码、折叠组、光标、批量选择及分栏现场。
- 保存失败保留输入；保存中防止重复提交，中文输入法 Enter 不提前提交。
- 日志向上滚动后暂停自动跟随，回到底部恢复；关闭查看器不取消远端构建。
- 既有窗口拖拽、系统关闭与退出策略沿用原实现，不引入后台驻留策略变更。
